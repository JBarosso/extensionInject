Politique de confidentialité — Injector Style

Dernière mise à jour : 22 septembre 2026

Injector Style est une extension Chrome qui permet d'appliquer du CSS personnalisé sur les sites web que vous visitez (édition visuelle, CSS par site, presets réutilisables).

Quelles données sont collectées ?

Aucune. Injector Style ne collecte, ne transmet et ne vend aucune donnée personnelle. L'extension ne contient aucun serveur distant, aucun outil d'analyse (analytics), aucun tracker et aucun appel réseau.

Où sont stockées vos configurations ?

Vos règles CSS, vos presets et vos préférences sont enregistrés uniquement en local sur votre appareil, via l'API chrome.storage.local du navigateur. Ces données ne quittent jamais votre ordinateur et ne sont partagées avec personne, y compris le développeur de l'extension.

Pourquoi ces permissions ?

  • storage — sauvegarder localement vos configurations CSS.
  • scripting — injecter votre CSS personnalisé dans la page.
  • activeTab — appliquer les modifications à l'onglet actif lorsque vous utilisez l'extension.
  • sidePanel — afficher l'interface de l'extension dans le panneau latéral de Chrome.
  • Accès à tous les sites (<all_urls>) — vous pouvez personnaliser n'importe quel site ; le CSS enregistré doit pouvoir être réappliqué automatiquement, quel que soit le site visité.

Suppression de vos données

Vous pouvez supprimer toutes les données de l'extension à tout moment en la désinstallant depuis chrome://extensions, ou en effaçant son stockage local via les outils de développement de Chrome.

Modifications de cette politique

Cette page peut être mise à jour si les fonctionnalités de l'extension évoluent. La date de dernière mise à jour est indiquée en haut de page.
